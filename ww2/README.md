# 1900–1991 历史省级区划与实际控制

本部分最初为 1939–1945 年的六个断面，后来用同一方法补充了 1900、1914、1918、1934 年的四个断面（见[下文](#19001934-年的四个断面)），以及 1946、1947、1948、1949、1953、1991 年的六个断面（见[下文](#19461991-年的六个断面)）。以下各节除特别说明外均指二战部分。

六个时间断面上全世界当日施行的省级区划，每个断面约 1,200 个省级单位。当时的县、地区都并入所属的省；国界或战线穿过一个省时，省按界线切成几块（`pieces`），各块分别记录归属。每个单位记录：

- 名称、层级、上级区划、施行期间、由几个下级区划合并而成；
- 所属政治单元（国家 / 殖民地 / 保护国 / 委任统治地）、法理宗主；
- 当日的实际控制者、控制方式、判定依据、所属阵营；
- 估计人口。

附六张可交互地图，有阵营、国家（法理领土）和控制国（实际控制区）等视图，地形和白色两种底图。

| 断面 | 事件 |
|---|---|
| 1939-09-01 | 德国入侵波兰，第二次世界大战在欧洲爆发 |
| 1940-07-01 | 法国停战后，德国控制西欧 |
| 1941-12-07 | 珍珠港事件当日，德军止步莫斯科城下 |
| 1942-11-01 | 轴心国扩张的最大范围（阿拉曼、斯大林格勒之前） |
| 1944-06-06 | 诺曼底登陆日 |
| 1945-09-02 | 日本签署投降书，战争结束 |

## 地图

打开地图的命令见仓库首页 [README](../README.md#打开方式)。页面上方切换断面，左侧切换视图：

| 视图 | 内容 |
|---|---|
| 阵营 | 按同盟国 / 轴心国 / 中立 / 前线着色；粗线为当日的法理国界和殖民地界 |
| 国家 | 每个国家按自己的法理领土着色（CShapes 当日的政治单元），不计占领；殖民地、保护国、委任统治地用宗主国颜色的浅色。各国颜色与控制国视图一致 |
| 控制国 | 各国的实际控制区。每个国家一种颜色，同一国家控制的地方连成一片，粗线为各国控制区的边界 |
| 人口密度 | 每块的估计人口除以面积 |
| 区划资料 | 每个地方的区划资料细到哪一级：省级、大区级，或只有整个国家 / 殖民地 |

底图有两种，在左侧“底图”切换（浏览器会记住选择）：

- **地形：** 分层设色加山体晕渲。高程取自 Terrarium 高程瓦片（缩放级 5，赤道处约 4.9 km 一像素），按海拔着色：低地浅绿，丘陵米黄，高原土黄，高山赭褐，6,000 m 以上转淡；再乘上西北光源的晕渲。
- **白色：** 白色海面、浅灰陆地、浅色政区，适合打印风格的阅读。

两种底图都另有一层只含明暗的山体阴影，叠在政区颜色之上，所以着色后山脉仍然清楚（图层开关“山体晕渲”）。

地名由地图在画布上直接绘制，随地图移动，不会漂移：

- 国名用小号宋体，位置是每块领土主体中离边界最远的点（polylabel），只在整个名字放得进领土的缩放级显示。控制国视图写实际控制国，其他视图写法理国家。
- 省名在放大后按面积从大到小显示。
- 河名沿河书写。Natural Earth 把每条河切成很多小段，名字用的是按河名拼接、平滑后的河道线。

控制国视图里，“国家”指当日实际统治这块土地的政权：

- 军事占领区、吞并区算作占领国。1942-11-01 从法国北部、比荷卢、丹麦、挪威到波兰、乌克兰、白俄罗斯、塞尔维亚、希腊大部都标为“德国”；日本占领的华北、华中、东南亚标为“日本”；英国的殖民地、保护国、委任统治地标为“英国”。
- 有自己政府的傀儡、附庸政权单列：满洲国、蒙疆、维希法国（含 1940–42 年听命于维希的殖民地）、意大利社会共和国、斯洛伐克、克罗地亚独立国。
- 1944 年盟军控制下的南意大利标为“意大利王国”；几国联合控制的地方标为“同盟国联军”“德意联军”；前线争夺区用斜线，不写国名。

点击分两级：

1. 第一次点击选中国家（控制国视图为实际控制国，其他视图为法理上的国家 / 殖民地）。其余地方变淡，面板显示人口、面积、省级单位数、所辖地区（或当日的各个实际控制者）和人口最多的省份。
2. 在该国范围内再点一次，进入省级：显示省的原名、类别、施行期间、合并了多少个县级 / 地区级区划、界线依据，以及这个省当日被切成的每一块由谁控制。面板顶部的国名可返回国家一级；点海面取消选中。

河流湖泊取自 Natural Earth 1:1000 万数据，按等级粗细不同，放大后逐级显示更小的河流；缩放到 4.3 级以上再载入欧洲、北美的细部水系，并沿河标注河名。湖泊用 1939–45 年的样子：不含 1945 年以后蓄水的水库，咸海、乍得湖、罗布泊用 1960 年代以前的轮廓。

## 1900–1934 年的四个断面

地图上方 1939 年之前另有四个标签页，由同一套脚本生成（设环境变量 `WW2_SET=early`，见 `scripts/ww2_common.py`），中间文件在 `work/early/`，数据库为 `db/divisions_1900_1934.sqlite`（表结构与二战数据库相同）。

| 断面 | 事件 | 阵营视图的四类 |
|---|---|---|
| 1900-08-14 | 八国联军攻入北京 | 八国联军各国（及其属地）／清廷（对列强宣战）／东南互保各省与其他国家／交战区 |
| 1914-08-04 | 英国对德宣战，第一次世界大战全面爆发 | 已参战的协约国／已参战的同盟国／中立国与尚未参战的国家／交战区 |
| 1918-11-11 | 贡比涅停战协定生效，第一次世界大战结束 | 协约国及其盟国／同盟国／中立国与退出大战的苏维埃俄国／交战区（俄国内战等） |
| 1934-10-16 | 中央红军开始长征 | 国际联盟成员国／已宣布退出国联的日本、德国及满洲国／非成员国／交战区 |

阵营的划分方式：

- **1900 年：** 八国联军为英、美、法、德、意、俄、日、奥匈，属地随宗主国。清廷 6 月 21 日对各国宣战；两江、湖广、两广、闽浙督抚与山东巡抚不奉诏，与列强约定“东南互保”，四川也随之，这些省份计入中立一类。
- **1914 年：** 只算 8 月 4 日已处于战争状态的国家。黑山（8 月 5 日）、日本（8 月 23 日）、奥斯曼帝国（11 月）、意大利（1915 年）此时尚未参战。
- **1918 年：** 苏维埃俄国 1918 年 3 月签订布列斯特和约，退出大战，计为中立；新成立的捷克斯洛伐克、波兰，以及俄国白军计入协约国一方。
- **1934 年：** 按国际联盟会籍。苏联、阿富汗、厄瓜多尔 1934 年 9 月加入；日本（1933 年 3 月）、德国（1933 年 10 月）已通知退出（两年后生效）。

### 区划

所有资料都按施行期间筛选，后来的区划不会用到更早的日期（例如 1900 年不会出现伪满洲国的省，1914 年的台湾不会出现 1920 年才设的州）：

- **OpenHistoricalMap：** 提取 1900–1945 年间施行的全部行政区划（`ww2_ohm.py`），覆盖德意志帝国各邦与普鲁士各省、奥地利各王室领地、匈牙利各州（vármegye）、克罗地亚-斯拉沃尼亚、英国、拉美各国、比利时、丹麦、朝鲜、英属印度各省和土邦、1934 年苏联各州和边疆区，以及俄罗斯帝国的一部分省份。OpenHistoricalMap 在 1918 年以前把整个匈牙利王国画成一个单位，覆盖在各州之上，这一层被略去，所以匈牙利各州本身就是省级单位。
- **美国：** 各县（Newberry 县界史，按施行日期）合并为州和领地，例如 1900 年的俄克拉何马、印第安、亚利桑那、新墨西哥领地。
- **中国：** 以 1928–45 年的省界（ENP-China、K. Lawson）合并或拆分为当时的单位，属复原（`basis = reconstructed_from_1928_outlines`），各省之间的界线变化不大，与蒙古、西藏的界线误差较大：
  - 1900 年：清朝各省，盛京、吉林、黑龙江三将军辖区，热河（承德府及卓索图、昭乌达二盟）、察哈尔、绥远各蒙旗地区，宁夏并入甘肃，西康并入四川，青海、西藏为办事大臣辖区，外蒙古、唐努乌梁海（轮廓取自今日蒙古国、图瓦共和国）；
  - 1914、1918 年：北京政府的直隶、奉天、京兆地方（按今北京市近似），热河、察哈尔、绥远、川边特别区，外蒙古（博克多汗国自治）；
  - 1934 年：国民政府各省，西康为特别区（雅安、西昌一带 1939 年以前属四川）。
- **其他：** 法国各省（1871–1918 年下莱茵、上莱茵、摩泽尔三省为德国的阿尔萨斯-洛林帝国直辖领地）、日本府县、朝鲜 13 道（1896 年起）、台湾州厅（1920 年起，之前为整个台湾）、菲律宾各省（1917 年起）、荷属东印度各州（1926–37 年按当时的归属分组，婆罗洲省 1938 年才设）、法属印度支那（暹罗 1904、1907 年割让的地方此前不计入）、缅甸各专区（1922 年以前为“掸邦”）、印度土邦、关东州（1898–1905 年为俄国租借地）。
- **没有省级资料的地方** 显示整个国家或殖民地：奥斯曼帝国、波斯、巴尔干各国、非洲大部、1934 年以前的荷属东印度，以及 OpenHistoricalMap 尚未录入的俄国省份（按人口计，1900、1914 年约一半、1918 年约三分之二没有省级资料）。

  按人口计，有省级（或大区级）区划的部分：1900 年 70%，1914 年 76%，1918 年 75%，1934 年 81%（二战各断面约 80%）。各断面、各政治单元的覆盖程度见 `ww2/coverage_1900_1934.csv`、`coverage_by_unit_1900_1934.csv`。

### 实际控制

规则在 `curated/region_control_1900_1934.csv`（约 65 条，写法与二战部分相同），加上 `curated/control_events.csv` 中的整国事件：

- **1900：** 天津、北京为八国联军占领；黑龙江为俄军入侵的交战区；奥兰治自由邦已被英军占领（5 月 28 日宣布吞并），德兰士瓦为布尔战争交战区；关东州为俄国租借地。
- **1914：** 德军 8 月 2 日占领卢森堡；外蒙古自 1911 年起自治；乌梁海 1914 年 4 月成为俄国保护地。
- **1918：** 停战当日德军仍占领比利时大部、卢森堡、法国阿登省和布里埃矿区，以及布列斯特和约后的波罗的海三国、白俄罗斯大部、普斯科夫、克里米亚，乌克兰为德奥扶植的盖特曼国；罗马尼亚的瓦拉几亚、多布罗加仍被同盟国占领，比萨拉比亚已并入罗马尼亚；意大利军队占领特伦蒂诺、南蒂罗尔、的里雅斯特、伊斯特拉和北达尔马提亚；斯洛文尼亚人、克罗地亚人和塞尔维亚人国，西乌克兰人民共和国（利沃夫为交战区），斯洛伐克仍由匈牙利管理；塞尔维亚、黑山已光复；协约国占领奥斯曼的伊拉克、巴勒斯坦、黎巴嫩，叙利亚、外约旦为费萨尔的阿拉伯政府，汉志、内志各自为政；俄国内战按 11 月的局面分为苏维埃俄国、全俄临时政府（鄂木斯克）及西伯利亚、乌拉尔、哥萨克各白军，北方区和海参崴的协约国干涉军，伏尔加河下游、北高加索等交战区，格鲁吉亚、亚美尼亚、阿塞拜疆，布哈拉、希瓦；中国南方为护法军政府（广东、广西、云南、贵州、四川及湘南、闽南）。
- **1934：** 东北四省（按 1928–45 年省界）为伪满洲国；中华苏维埃共和国的中央苏区（瑞金一带）和川陕苏区按县近似；萨尔盆地由国际联盟管理；但泽自由市；查科战争前线、阿斯图里亚斯起义为交战区。

两处 CShapes 的特别处理：1918-11-11 的 CShapes 没有画出拉脱维亚（布列斯特和约之后、11 月 18 日独立之前），这块地算作俄国；塞尔维亚、黑山在 CShapes 中仍是“奥匈占领”，实际已在 11 月初光复，改为本国。

几处小的租借地（胶州湾、威海卫、广州湾）面积不到省级切块的下限，没有单独切出，只在城市提示中说明。

人口的估计方法与二战部分相同，用 1900–2000 数据库中各政治单元当年的人口。城市在 `curated/cities_1900_1934.csv`，多一列 `dates` 写明这一行用于哪些断面，所以改过名的城市每个名字一行（圣彼得堡、彼得格勒、列宁格勒）。

## 1946–1991 年的六个断面

1945 年之后另有六个标签页，同样由这套脚本生成（设环境变量 `WW2_SET=postwar`），中间文件在 `work/postwar/`，数据库为 `db/divisions_1946_1991.sqlite`（表结构与二战数据库相同）。

| 断面 | 事件 | 阵营视图的四类 |
|---|---|---|
| 1946-06-26 | 国民政府军进攻中原解放区，国共内战全面爆发 | 西方盟国（美英法等）及其属地／苏联势力范围（含中共控制区）／其他国家／交战区 |
| 1947-08-15 | 印度、巴基斯坦分治独立 | 西方阵营（杜鲁门主义、马歇尔计划）／苏联阵营／其他国家／交战区 |
| 1948-09-12 | 辽沈战役开始；朝鲜半岛南北两个政府已经成立 | 西方阵营／苏联阵营（含中共控制区）／其他国家（含南斯拉夫）／交战区 |
| 1949-10-01 | 中华人民共和国成立 | 北约与美国的盟友／苏联阵营（含中华人民共和国）／其他国家／交战区 |
| 1953-07-27 | 朝鲜停战协定签署 | 北约、澳新美与美国在亚洲的盟友／苏联阵营、中华人民共和国、朝鲜／其他国家／交战区 |
| 1991-12-26 | 苏联解体 | 北约成员国／独联体国家／其他国家／交战区 |

阵营的划分方式：

- **1946 年：** 按丘吉尔 1946 年 3 月“铁幕”演说的说法。苏联、东欧各国、蒙古、德奥的苏占区、朝鲜三八线以北，以及中共、伊朗的阿塞拜疆人民政府和马哈巴德共和国、新疆三区等苏联支持的政权为一方；美、英、法及其自治领和殖民地、比荷卢、挪威、丹麦、冰岛、希腊、土耳其和中华民国为另一方。
- **1947 年：** 在此基础上加入意大利（马歇尔计划）。
- **1948 年：** 加入韩国，朝鲜计入苏联一方；南斯拉夫 6 月被开除出共产党情报局，计入其他国家。
- **1949 年：** 北约 12 个创始国，加上希腊、土耳其、中华民国、韩国、菲律宾、澳大利亚、新西兰；苏联一方加入中华人民共和国和越盟。
- **1953 年：** 北约 14 国（1952 年希腊、土耳其加入）、联邦德国、澳新美同盟、日本、韩国、菲律宾、台湾的中华民国；苏联一方为苏联、东欧各国、民主德国、蒙古、中华人民共和国、朝鲜、越盟。
- **1991 年：** 北约 16 国；独联体为 12 月 21 日签署阿拉木图宣言的 11 个原苏联共和国（波罗的海三国和格鲁吉亚不在内）。

### 区划

## 省级区划：只用当时施行的区划

每个断面只用当日施行的区划，**不用现代政区代替**。构建分两步：

1. `ww2_histunits.py` 把各套历史资料从细到粗铺满陆地，得到每个地方当日已知最细的区划（县级、地区级、省级、大区级，或整个国家 / 殖民地）。
2. `ww2_provinces.py` 把县级和地区级单位并入它们所属的省，只留省级区划：
   - 所属的省取 `ww2_histunits.py` 记下的上级、再上级中第一个省级单位；中间隔着地区级（如普鲁士的行政区）就再往上找一级。各套资料自带的归属优先：朝鲜各郡归 13 道，美国各县归州，台湾郡市归五州三厅，缅甸 1931 年各县归 7 个专区和掸邦、克伦尼邦，法属印度支那各省归东京、安南、交趾支那、柬埔寨、老挝，荷属东印度各州（residentie）归各省（gouvernement）。
   - 同名的省级单位相邻时合为一个（两套资料画了同一个省）；不同政治单元里的同名单位（如比利时与荷兰的 Limburg）不合并。
   - 上面没有任何上级的县级或地区级单位，本身就是当时的一级区划，保留为省级。例如爱尔兰各郡、1940 年意大利艾米利亚各省、匈牙利各州（vármegye）、罗马尼亚各县（județ）、荷属东印度直属总督的各州。其中很小的（城区、市镇，不足 300 km²），或所在政治单元几乎没有省级资料的，并入相邻单位。
   - 某国大部分已有省级资料、只剩零星没覆盖到的小块（不足 5,000 km² 且不足该政治单元 3%），并入最近的省。
   - 省的轮廓是它合并的各单位轮廓之和（`basis = merged_subunits`，`merged_units` 为合并的单位数），原来被县级单位切掉一部分的省级单位恢复完整。

`ww2_provinces.py` 读取 `work/ww2/` 中县级的中间文件；这些文件不在时，可以改读县级的数据库：
`python3 ww2_provinces.py --county-db <县级数据库>`。本版即由 2026-10-03 发布的县级数据库（git 历史中的
`db/ww2_divisions_1939_1945.sqlite`）生成，几何精度与该库相同（简化 0.006°）。

层级（`tier`）现在只有四种：

| 层级 | 内容 |
|---|---|
| 3 省级 | 当时的省、州、道、府县、省（département）、专区等一级区划。来源：OpenHistoricalMap 第 4 级；蒙疆三政厅、伪满洲国各省、中华民国各省（1928–45）、朝鲜 13 道、台湾五州三厅、菲律宾 1939 年各省、1940 年日本各府县、1939 年法国各省、1931 年印度土邦；以及由县级、地区级资料合并而成的省（美国各州、缅甸各专区、法属印度支那、荷属东印度、普鲁士各省等） |
| 4 大区级 | OpenHistoricalMap 第 3 级（如苏联各加盟共和国、帝国专员辖区），只用在没有省级资料的地方 |
| 5 整个国家 / 殖民地 | 当日的 CShapes 2.0 轮廓，用于以上各层都没有覆盖的地方 |
| 6 岛屿属地 | CShapes 没有画出的小属地（关岛、南洋群岛、科威特、多德卡尼斯群岛、千岛群岛等，见 `scripts/ww2_territories.py`） |

OpenHistoricalMap 的行政区划都带 `start_date` / `end_date`，按断面日期筛选。例如：
- 1939 年的波兰省份；
- 1942 年的总督府各区和帝国专员辖区；
- 1942 年的苏联各州。

还有两组单位的轮廓取自今日数据，因为这些单位本身在 1939–1945 年存在，界线基本没变（`basis = present_day_outline_same_unit`）：

- **日本 47 府县：** 府县界自 1888 年（冲绳 1879 年）以来基本不变，名称用 1940 年的“府 / 県 / 庁”。
- **法国 90 个省：** 用 1939 年的名称与范围，例如 Seine-Inférieure、Basses-Pyrénées、Côtes-du-Nord，Corse 合为一省。
  - Seine 与 Seine-et-Oise 由 1968 年后的七个省合并而成，误差约 43 个市镇；
  - Alpes-Maritimes 含 1947 年才划归法国的 Tende、La Brigue。

  这些差异都在单位的 `note` 中注明。

### 边界穿过的省份

国界或战线穿过一个省时，这个省不整个划给一方，而是按界线切开：

- 省跨两个政治单元（CShapes 当日的国界、殖民地界）时，按国界切开；
- 省内实际控制者不同（前线、吞并、占领区分界）时，按控制者切开。控制者是在合并前的县级、地区级单位上判定的（见下节），所以切线保留了县一级的精度。例如 1942 年法国的占领区分界线穿过夏朗德、维埃纳、安德尔-卢瓦尔、谢尔、阿列等省，同年东线的前线穿过沃罗涅日等州。

切开的每一块是 `pieces` 中的一条，`control_split = 1`。不足 5 km² 的碎块并入同省最大的一块。1942-11-01 有 143 个省被切开。

### 覆盖程度

按人口计（`ww2/coverage.csv`，各断面基本相同，以 1942-11-01 为例）：

| 层级 | 单位数 | 人口占比 |
|---|---|---|
| 省级 | 1,056 | 78.1% |
| 大区级 | 26 | 2.4% |
| 整个国家 / 殖民地 | 117 | 19.4% |
| 岛屿属地 | 11 | 0.03% |

只有国家或殖民地一级的，主要是埃及、土耳其、埃塞俄比亚、伊朗、比属刚果、英埃苏丹、尼泊尔、希腊、法属摩洛哥、保加利亚和大部分非洲殖民地；英属尼日利亚、泰国、比利时、葡萄牙、阿富汗、伊拉克等只有零星省级资料（详见 `coverage_by_unit.csv`）。

OpenHistoricalMap 是众包数据，各国录入程度差别很大，各国的“省级”也不完全对应：英国的第 4 级是英格兰和威尔士、苏格兰、北爱尔兰，瑞典有些地方录入的是更细的百户区（härad）。少数单位的界线与相邻资料不完全吻合：海岸线一律以今日陆地轮廓为准，残留的小块陆地并入相邻单位。

## 实际控制的判定（优先级从低到高）

1. CShapes 2.0 在该日期的国界与宗主（殖民地归宗主国）。
2. `control_events.csv`：整个政治单元的被占领 / 傀儡政权等事件（如丹麦、挪威、荷兰、比利时、希腊）。
3. 东亚历史图层：
   - 满洲国：1945-09-02 改为苏军；
   - 蒙疆；
   - 1942 年日占区：1939、1940、1944 年沿用，标为近似；1945-09-02 标为“待受降”；
   - 中共抗日根据地：1941、1942 年；
   - 1941 年割让给泰国的柬埔寨、老挝领土。
4. `ww2_region_control.csv` 的分区规则，约 100 条，按文件顺序执行，后者覆盖前者。例如：
   - 法国：占领区、维希区、阿尔萨斯—摩泽尔；
   - 自由法国：1941–42 年的法属赤道非洲和喀麦隆、新喀里多尼亚、叙利亚、黎巴嫩；
   - 1942 年英军占领的马达加斯加；
   - 法属印度支那：1941–44 年日军进驻；
   - 东线各州在各断面的归属，包括“前线争夺”；
   - 南斯拉夫的瓜分、北特兰西瓦尼亚；
   - 意大利 1944 年战线；
   - 伊朗占领区、太平洋岛屿；
   - 德国和奥地利的占领区（1945）。

规则用今日的地名书写（如 “Kursk Oblast”、Croatia），因为战时的瓜分线和前线不沿任何一套行政区划。
控制者在合并成省之前、在最细的历史区划上判定，再按控制者把省切开（见上节）。
构建时，今日政区只作为内部参照（`scripts/ww2_reference.py`），从不作为行政区划输出：

- 一个历史单位内各处规则给出的控制者相同，它就整块归属；
- 不同时，按参照区把它切成几块（`pieces`）。

例如 1941 年的南斯拉夫在没有下级资料时是一个单位，按克罗地亚独立国、德军、意大利、匈牙利、保加利亚的占领范围切开。
面积不到 8% 且不足 1,500 km² 的碎块并入主块。

阵营 `bloc` 分四类：

- `allied`：同盟国一方；
- `axis`：轴心国及其附庸、占领区；
- `neutral`：中立国及尚未参战的国家，维希法国记为中立；
- `contested`：前线争夺。

阵营按断面划分，并作了简化：

- 英法及其殖民地、中华民国自 1939-09-01 起计入同盟国一方（英法于 9 月 3 日宣战）；
- 苏联、美国自 1941-12-07 断面起计入同盟国；
- 匈、罗、保、芬在 1941–1944 断面计入轴心国，罗、保在 1945 断面计入同盟国；
- 拉美等国按对轴心国宣战的时间逐步计入。

`control_confidence = approximate` 表示控制按整区分配，或沿用临近年份的范围，真实前线可能从单位内穿过（地图上为斜线）。

## 人口

人口为估计值，分两步：

1. 用 GHS-POP 1975 年人口格网（30″）算出每块在本政治单元内的人口占比；
2. 乘以该单元当年的人口（来自本仓库 1900–2000 数据库的 `unit_year` 表）。美国另按各州人口普查数校准；小属地用约 1940 年的近似总数。

它反映的是 1975 年的人口分布格局，不是当时的普查数。人口在合并成省之前、按最细的历史区划算出，省和省内各块的人口是所含单位之和。

## 表结构（SQLite）

| 表 | 内容 |
|---|---|
| `meta`, `sources` | 说明、坐标系、构建时间；数据来源、引用、许可证 |
| `snapshots` | 六个断面及各阵营人口 |
| `admin_units` | 历史省级区划：名称（原文 / 中文 / 英文）、层级（3 省级 / 4 大区级 / 5 整个政治单元 / 6 岛屿属地）、类别、界线依据、来源、备注、施行起止日期、上级区划、合并的县级 / 地区级单位数（`merged_units`）、所在断面、面积、标注点、几何（GeoJSON，简化 0.006°，坐标保留 3 位小数） |
| `pieces` | 每个省在各断面被国界或战线切成的块（`piece_id` 为 `单位~序号`），几何为空表示与单位相同 |
| `piece_snapshot` | 每个断面每一块：所属政治单元、控制记录、所在的省是否被切开（`control_split`）、面积、估计人口 |
| `unit_snapshot` | 每个断面的政治单元：名称、地位、法理宗主、局部控制事件 |
| `controls` | 控制记录：实际控制者、细节、控制方式、判定来源、可信度、阵营 |
| `pop_methods` | 人口估计方法 |
| `snapshot_full`（视图） | 以上各表连成的宽表，一行一块一个断面，查询时直接用它 |
| `control_rules`, `control_events` | 规则与事件原文（`row` 为 CSV 行号，对应 `control_source = rule:<行号>`） |

```sql
-- 1942-11-01 日本实际控制的省份，按估计人口排序
SELECT name, name_zh, tier_zh, unit_name_zh, population_est
FROM snapshot_full WHERE snapshot = '1942-11-01' AND controller_gwcode = 740
ORDER BY population_est DESC LIMIT 20;

-- 1942 年苏联境内德国设立的行政单位
SELECT DISTINCT name, start_date, end_date, parent
FROM admin_units WHERE snapshots LIKE '%1942-11-01%' AND name LIKE 'Generalbezirk%';

-- 各断面各阵营的估计人口
SELECT snapshot, bloc, SUM(population_est) FROM snapshot_full GROUP BY snapshot, bloc;
```

## 地图数据格式（`ww2/maps/data/`）

| 文件 | 内容 |
|---|---|
| `geo.bin` | 所有断面用到的块（省，及被国界、战线切开的部分；填色用） |
| `geo-admin.bin` | 省级区划轮廓（画省界用） |
| `geo-units.bin` | CShapes 政治单元边界（阵营视图的国界） |
| `geo-ctrl.bin` | 各断面每个国家的实际控制区，已合并成片（控制国视图的边界和选中轮廓） |
| `admin.json` | 省级区划的静态属性（列式存储：每列为 `lut` 去重表 + `idx` 下标），`feature_admin` 把块对到所属的省，`merged` 为合并的下级单位数 |
| `snap-<日期>.json` | 该断面出现的块、当日施行的省、阵营、可信度、估计人口和控制属性；`countries` 为控制国视图的国家（键、中英文名、颜色、阵营、人口、面积、省数、在 `geo-ctrl.bin` 中的序号、所辖地区），`country` 把每块对到国家；`nations` / `nation` 为国家视图的法理政治单元及颜色；`country_labels`、`unit_labels` 为国名的位置（经纬度）及该处可容纳的宽度和高度（Web 墨卡托单位，页面据此判断各缩放级是否显示） |
| `relief/` | 地形底图：`r<缩放级>_<列>_<行>.webp` 为分层设色晕渲，`s…` 为只含明暗的山体阴影；缩放级 0–5，每级切成 2048 像素的图块，页面自己从中切出 256 像素瓦片（`ww2_relief.py` 生成） |
| `glyphs/sans/` | 拉丁、西里尔等字母的字形（OpenMapTiles 字库的 Noto Sans）；汉字由浏览器本地绘制 |
| `hydro.json` | Natural Earth 1:1000 万河流与湖泊（`k` 为 `r` 河流、`l` 湖泊、`n` 标注河名用的拼接河道；`r` 为等级，`n` 为中文名；湖泊为 1939–45 年的样子） |
| `hydro-detail.json` | 欧洲、北美的细部河流与湖泊，放大后才载入 |

四个 `.bin` 文件的编码相同：逐个要素写 varint 序列，依次为多边形数 → 每个多边形的环数 → 每个环的点数，后接 zigzag 编码的坐标差分。坐标单位为 1/1000 度，差分在同一要素内连续累计。解码函数见 `index.html` 的 `decodeGeo`。
