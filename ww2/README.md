# 1939–1945 历史行政区划与实际控制

六个时间断面上全世界当日施行的行政区划，每个断面约 5,600 个历史单位。每个单位记录：

- 名称、层级、上级区划、施行期间；
- 所属政治单元（国家 / 殖民地 / 保护国 / 委任统治地）、法理宗主；
- 当日的实际控制者、控制方式、判定依据、所属阵营；
- 估计人口。

附六张可交互地图。

| 断面 | 事件 |
|---|---|
| 1939-09-01 | 德国入侵波兰，第二次世界大战在欧洲爆发 |
| 1940-07-01 | 法国停战后，德国控制西欧 |
| 1941-12-07 | 珍珠港事件当日，德军止步莫斯科城下 |
| 1942-11-01 | 轴心国扩张的最大范围（阿拉曼、斯大林格勒之前） |
| 1944-06-06 | 诺曼底登陆日 |
| 1945-09-02 | 日本签署投降书，战争结束 |

## 行政区划：只用当时施行的区划

每个断面只用当日施行的区划，**不用现代政区代替**。同一地点有多套历史资料时，用最细的一套。
没有县级资料的地方用当时更高一级的区划；连省级资料也没有的，整个国家或殖民地作为一个单位。
具体分六级（`tier`）：

| 层级 | 来源（按优先顺序） |
|---|---|
| 1 县级 | 美国各县（Newberry《美国县界历史地图集》，带逐日起止日期）；台湾 1930 年郡、市（中研院）；朝鲜郡、府（据国史编纂委员会 1914–26 年地点资料重建）；缅甸 1931 年县；OpenHistoricalMap 第 6 级 |
| 2 地区级 | OpenHistoricalMap 第 5 级（如普鲁士的行政区）；关东州；荷属东印度 1941 年州（residentie）；法属印度支那各省 |
| 3 省级 | 蒙疆三政厅、伪满洲国各省、中华民国各省（1928–45）、朝鲜 13 道、台湾五州三厅、菲律宾 1939 年各省；1940 年日本各府县；1939 年法国各省；OpenHistoricalMap 第 4 级；1931 年印度土邦 |
| 4 大区级 | OpenHistoricalMap 第 3 级（如苏联各加盟共和国、帝国专员辖区） |
| 5 整个国家 / 殖民地 | 当日的 CShapes 2.0 轮廓，用于以上各层都没有覆盖的地方 |
| 6 岛屿属地 | CShapes 没有画出的小属地（关岛、南洋群岛、科威特、多德卡尼斯群岛、千岛群岛等，见 `scripts/ww2_territories.py`） |

OpenHistoricalMap 的行政区划都带 `start_date` / `end_date`，按断面日期筛选。例如：
- 1939 年的波兰省份；
- 1942 年的总督府各区和帝国专员辖区；
- 1942 年的苏联各州。

还有两组单位的轮廓取自今日数据，因为这些单位本身在 1939–1945 年存在，界线基本没变（`basis = present_day_outline_same_unit`）：

- **日本 47 府县：** 府县界自 1888 年（冲绳 1879 年）以来基本不变，名称用 1940 年的“府 / 県 / 庁”。
- **法国 90 个省：** 用 1939 年的名称与范围，例如 Seine-Inférieure、Basses-Pyrénées、Côtes-du-Nord，Corse 合为一省。
  - Seine 与 Seine-et-Oise 由 1968 年后的七个省合并而成，误差约 43 个市镇；
  - Alpes-Maritimes 含 1947 年才划归法国的 Tende、La Brigue。

  这些差异都在单位的 `note` 中注明。

### 覆盖程度

按人口计（`ww2/coverage.csv`，各断面基本相同，以 1942-11-01 为例）：

| 层级 | 单位数 | 人口占比 |
|---|---|---|
| 县级 | 4,171 | 11.1% |
| 地区级 | 311 | 6.8% |
| 省级 | 922 | 60.3% |
| 大区级 | 26 | 2.4% |
| 整个国家 / 殖民地 | 142 | 19.4% |
| 岛屿属地 | 11 | 0.03% |

各国的情况（1942-11-01，详见 `coverage_by_unit.csv`）：

- **县级：** 美国、朝鲜、台湾、缅甸、秘鲁，以及德国约四分之一人口（OpenHistoricalMap 已录入的 Landkreis）、意大利约五分之一（各省）、英国和爱尔兰的部分郡。
- **省级：** 中华民国、伪满洲国、日本、苏联大部、英属印度约四分之三、法国、西班牙、波兰、荷属东印度、法属印度支那、菲律宾、巴西、墨西哥、加拿大、澳大利亚、南非等。
- **只有国家或殖民地一级：** 埃及、伊朗、埃塞俄比亚、希腊、比利时、尼泊尔、法属摩洛哥、比属刚果、英埃苏丹，以及土耳其、泰国、罗马尼亚、南斯拉夫、捷克斯洛伐克、荷兰、葡萄牙、阿富汗的大部分地区。

### 为什么不是处处都到县级

1939–1945 年县级界线的权威数据集存在，但这次构建所在环境的网络策略屏蔽了它们的下载地址：

| 域名 | 数据 |
|---|---|
| `dataverse.harvard.edu` | CHGIS v6：1911 年中国县界；TRF-GIS：1870–1940 年法国区、县 |
| `mosaic.ipums.org` | MPIDR：1871–1945 年德国逐年县界，1930 年欧洲各国区划 |
| `www.istat.it` | 1936 年意大利各省 |
| `nlftp.mlit.go.jp` | 1920 年日本市町村界，可合并为郡 |

在环境设置中允许这些域名后，可以作为新的 `cand(...)` 图层接入 `scripts/ww2_histunits.py`，优先级排在同级 OpenHistoricalMap 之前即可。

OpenHistoricalMap 是众包数据，各国录入程度差别很大。少数单位的界线与相邻资料不完全吻合：海岸线一律以今日陆地轮廓为准，残留的小块陆地并入相邻单位。

## 实际控制的判定（优先级从低到高）

1. CShapes 2.0 在该日期的国界与宗主（殖民地归宗主国）。
2. `control_events.csv`：整个政治单元的被占领 / 傀儡政权等事件（如丹麦、挪威、荷兰、比利时、希腊）。
3. 东亚历史图层：
   - 满洲国：1945-09-02 改为苏军；
   - 蒙疆；
   - 1942 年日占区：1939、1940、1944 年沿用，标为近似；1945-09-02 标为“待受降”；
   - 中共抗日根据地：1941、1942 年；
   - 1941 年割让给泰国的柬埔寨、老挝领土。
4. `ww2_region_control.csv` 的分区规则，约 100 条，按文件顺序执行，后者覆盖前者。例如：
   - 法国：占领区、维希区、阿尔萨斯—摩泽尔；
   - 自由法国：1941–42 年的法属赤道非洲和喀麦隆、新喀里多尼亚、叙利亚、黎巴嫩；
   - 1942 年英军占领的马达加斯加；
   - 法属印度支那：1941–44 年日军进驻；
   - 东线各州在各断面的归属，包括“前线争夺”；
   - 南斯拉夫的瓜分、北特兰西瓦尼亚；
   - 意大利 1944 年战线；
   - 伊朗占领区、太平洋岛屿；
   - 德国和奥地利的占领区（1945）。

规则用今日的地名书写（如 “Kursk Oblast”、Croatia），因为战时的瓜分线和前线不沿任何一套行政区划。
构建时，今日政区只作为内部参照（`scripts/ww2_reference.py`），从不作为行政区划输出：

- 一个历史单位内各处规则给出的控制者相同，它就整块归属；
- 不同时，按参照区把它切成几块（`pieces`）。

例如 1941 年的南斯拉夫在没有下级资料时是一个单位，按克罗地亚独立国、德军、意大利、匈牙利、保加利亚的占领范围切开。
面积不到 8% 且不足 1,500 km² 的碎块并入主块。

阵营 `bloc` 分四类：

- `allied`：同盟国一方；
- `axis`：轴心国及其附庸、占领区；
- `neutral`：中立国及尚未参战的国家，维希法国记为中立；
- `contested`：前线争夺。

阵营按断面划分，并作了简化：

- 英法及其殖民地、中华民国自 1939-09-01 起计入同盟国一方（英法于 9 月 3 日宣战）；
- 苏联、美国自 1941-12-07 断面起计入同盟国；
- 匈、罗、保、芬在 1941–1944 断面计入轴心国，罗、保在 1945 断面计入同盟国；
- 拉美等国按对轴心国宣战的时间逐步计入。

`control_confidence = approximate` 表示控制按整区分配，或沿用临近年份的范围，真实前线可能从单位内穿过（地图上为斜线）。

## 人口

人口为估计值，分两步：

1. 用 GHS-POP 1975 年人口格网（30″）算出每块在本政治单元内的人口占比；
2. 乘以该单元当年的人口（来自本仓库 1900–2000 数据库的 `unit_year` 表）。美国另按各州人口普查数校准；小属地用约 1940 年的近似总数。

它反映的是 1975 年的人口分布格局，不是当时的普查数。

## 表结构（SQLite）

| 表 | 内容 |
|---|---|
| `meta`, `sources` | 说明、坐标系、构建时间；数据来源、引用、许可证 |
| `snapshots` | 六个断面及各阵营人口 |
| `admin_units` | 历史行政区划：名称（原文 / 中文 / 英文）、层级、类别、界线依据、来源、备注、施行起止日期、上级区划、所在断面、面积、标注点、几何（GeoJSON，简化 0.006°，坐标保留 3 位小数） |
| `pieces` | 每个单位在各断面被切成的块（`piece_id` 为 `单位@政治单元~序号`），几何为空表示与单位相同 |
| `piece_snapshot` | 每个断面每一块：所属政治单元、控制记录、是否因控制者不同而切开、面积、估计人口 |
| `unit_snapshot` | 每个断面的政治单元：名称、地位、法理宗主、局部控制事件 |
| `controls` | 控制记录：实际控制者、细节、控制方式、判定来源、可信度、阵营 |
| `pop_methods` | 人口估计方法 |
| `snapshot_full`（视图） | 以上各表连成的宽表，一行一块一个断面，查询时直接用它 |
| `control_rules`, `control_events` | 规则与事件原文（`row` 为 CSV 行号，对应 `control_source = rule:<行号>`） |

```sql
-- 1942-11-01 日本实际控制的行政区划，按估计人口排序
SELECT name, name_zh, tier_zh, unit_name_zh, population_est
FROM snapshot_full WHERE snapshot = '1942-11-01' AND controller_gwcode = 740
ORDER BY population_est DESC LIMIT 20;

-- 1942 年苏联境内德国设立的行政单位
SELECT DISTINCT name, start_date, end_date, parent
FROM admin_units WHERE snapshots LIKE '%1942-11-01%' AND name LIKE 'Generalbezirk%';

-- 各断面各阵营的估计人口
SELECT snapshot, bloc, SUM(population_est) FROM snapshot_full GROUP BY snapshot, bloc;
```

## 地图数据格式（`ww2/maps/data/`）

| 文件 | 内容 |
|---|---|
| `geo.bin` | 所有断面用到的块（填色用） |
| `geo-admin.bin` | 历史行政区划轮廓（画界线用） |
| `geo-units.bin` | CShapes 政治单元边界 |
| `admin.json` | 行政区划的静态属性（列式存储：每列为 `lut` 去重表 + `idx` 下标），`feature_admin` 把块对到所属单位 |
| `snap-<日期>.json` | 该断面出现的块、当日施行的单位、阵营、可信度、估计人口和控制属性 |
| `terrain.png` | Web 墨卡托地形晕渲（透明度表示阴影） |
| `hydro.json` | 主要河流与湖泊 |

三个 `.bin` 文件的编码相同：逐个要素写 varint 序列，依次为多边形数 → 每个多边形的环数 → 每个环的点数，后接 zigzag 编码的坐标差分。坐标单位为 1/1000 度，差分在同一要素内连续累计。解码函数见 `index.html` 的 `decodeGeo`。
