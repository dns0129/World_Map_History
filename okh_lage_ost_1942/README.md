# 1942 年东线态势图（德国陆军总司令部 “Lage Ost”）

1942 年每月 1 日的德国陆军总司令部（OKH）东线态势图原件扫描，共 12 期 25 张：

- **blatt1（北图）：** 列宁格勒—莫斯科—库尔斯克（1–8 月为竖幅，9 月起向东扩到伏尔加河，右上角缺一块）；
- **blatt2（南图）：** 乌克兰、顿河、克里米亚、高加索（9 月起向南扩到外高加索和土耳其北部）；
- **2 月 1 日一期分三张：** blatt1 为波罗的海至莫斯科，blatt2 为乌克兰西部至黑海西北岸，blatt3 为哈尔科夫—顿巴斯—亚速海一段。

各张底图的拼接方式和范围按当日的战线变化，文件名中的 blatt 编号与档案中的页序一致。

## 来源

- **原件：** 德国陆军总司令部总参谋部作战处 IIIb 科（Operationsabteilung IIIb des Generalstabs des Heeres im OKH）每日绘制的 “Lage Ost”（东线态势），底图为 1:100 万 “Operationskarte Osten”。蓝色为德军及盟军的集团军、军、师和前线，红色为德方判断的苏军集团军、军、师位置。图上的 “Stand … abds.” 指当日晚间的态势。
- **收藏：** 俄罗斯联邦国防部中央档案馆（ЦАМО / CAMO）第 500 号全宗（缴获德军文件）第 12457 号目录 “Karten zur Lage Ost”，每天一卷（Akte）。
- **数字化：** 俄德德国文件数字化项目 [germandocsinrussia.org](https://wwii.germandocsinrussia.org/de/nodes/13051-opis-12457-karty-polozheniya-gruppy-armiy-sever)。扫描件上的水印和 “CAMO_500_12457_…” 编号为该项目所加。

## 分辨率与重新下载

网站只提供最宽 1966 px 的预览，原始扫描（约 9000 px）只以 256 px 地图瓦片的形式提供。这里的图由 `scripts/okh_lage_ost.py` 把第 5 级瓦片拼接而成，高度 4096 px（约为原扫描的 45%~60%），德军军番号和苏军集团军、师番号都可辨认。需要接近原始分辨率（高度 8192 px，每张约 20 MB）时运行：

```sh
pip install requests pillow
cd scripts
python3 okh_lage_ost.py --zoom 6 --out ../okh_lage_ost_1942_full
```

## 使用条件

使用这些文件须遵守 germandocsinrussia.org 的用户协议（不得传播其中的个人信息等）；引用时请注明 “ЦАМО РФ, Ф. 500, Оп. 12457, Д. <卷号>”，并注明数字化项目。
